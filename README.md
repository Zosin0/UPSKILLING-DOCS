Este repositorio contem apenas documentacao tecnica e executiva do trabalho de UpSkilling em GitHub Actions, sem dependencia de codigo fonte e sem referencias a repositórios da organizacao.

## Objetivo

Consolidar o escopo da iniciativa de Shift Left em uma base unica para:

- entrega formal do trabalho;
- referencia tecnica para colegas;
- apoio de apresentacao para banca;
- reaproveitamento em PDF e slides.

## Como usar para entrega

1. Ler os documentos em ordem numerica.
2. Gerar PDF unico ou por capitulo.
3. Usar o roteiro da secao 08 para apresentacao.
