# 06. Governanca e Criterio de Gate

## Regra de aprovacao

O gate final e aprovado somente quando todos os controles obrigatorios estao conformes.

Controles verificados:

1. Build/Test com sucesso
2. Cobertura minima atingida
3. SAST sem falha de execucao
4. Dependency Review conforme politica
5. SCA valido conforme severidade e origem

## Propriedades de governanca

- decisao unica e rastreavel;
- motivo da decisao registrado em resumo tecnico;
- politica reproduzivel entre projetos.

## Beneficio para auditoria

- evidencia objetiva de criterio;
- trilha clara entre finding, politica e decisao;
- base para melhoria continua do processo.
