# 07. Integracoes Possiveis com GitHub Actions

1. DAST com OWASP ZAP em ambiente de teste
2. Geracao de SBOM e assinatura de artefatos

1. Policy as Code para compliance

- aumento da confianca no pipeline;
- reducao do tempo de analise manual;
- melhoria continua da postura de seguranca.
